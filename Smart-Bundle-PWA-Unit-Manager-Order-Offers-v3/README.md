# Smart Bundle — Complete PWA package

این بسته کامل برای انتشار اپ **Smart Bundle** با GitHub Pages آماده شده است. فایل‌های قبلی موردنیاز حذف نشده‌اند و لوگو، آیکن‌ها و فونت محلی یکان همگی در بسته وجود دارند.

## محتویات
- `index.html` — داشبورد و رابط کاربری
- `manifest.webmanifest` — نام و تنظیمات نصب PWA
- `sw.js` — سرویس‌ورکر با کش نسخه `smart-bundle-v6`
- `assets/fonts/Yekan.ttf` — فونت یکان ارسالی
- `assets/tosan-techno-logo.png` — لوگوی توسن تکنو
- `assets/icon-192.png` و `assets/icon-512.png` — آیکن‌های PWA

## منطق محاسبه باندلینگ در این نسخه
- بودجه باندلینگ هر سفارش = تعداد کشلس × (قیمت فروش کشلس − بهای تمام‌شده کشلس − سود ثابت هر کشلس) − تعداد کارتخوان × بودجه بازاریابی هر کارتخوان.
- بودجه باندلینگ قابل تخصیص مستقیماً قیمت بسته‌ای کارتخوان را کاهش می‌دهد؛ بنابراین با افزایش تعداد کشلس، قیمت کارتخوان دوباره محاسبه و پایین‌تر می‌آید، تا سقف کاهش برابر با قیمت پایه کارتخوان.
- تعداد کارتخوان مضرب ۵ نیست؛ تعدادهای صحیح از ۱ به بالا پذیرفته می‌شوند.
- قیمت هدف رقابتی مرجع مقایسه است، نه سقف تخفیف. اگر بودجه کافی نباشد، پیام هشدار نشان داده می‌شود؛ اگر بودجه منفی باشد، بسته غیرمجاز است.

## انتشار در GitHub Pages
1. فایل ZIP را استخراج کن.
2. تمام محتویات داخل پوشه `Smart-Bundle-GitHub-Complete` را در ریشه مخزن GitHub خودت (`Bundle`) آپلود کن؛ اگر GitHub پرسید، فایل‌های موجود را با این نسخه جایگزین کن.
3. تغییرات را Commit کن.
4. در مخزن، از **Settings → Pages**، انتشار از شاخه موردنظر و پوشه `/ (root)` را فعال کن.
5. پس از انتشار، سایت را با HTTPS باز کن. برای مشاهده نسخه تازه، در صورت نمایش نسخه قبلی، صفحه را یک بار کامل ببند و دوباره باز کن.

## نکته مهم
- پوشه `assets` این بسته کامل است و شامل لوگو، دو آیکن و فونت می‌شود؛ در این نسخه نیازی به حفظ جداگانه فایل‌های این مسیرها از ZIP قبلی نیست.
- عنوان صفحه آغازین «سامانه طراحی مدل فروش محصولات کارتخوان توسن تکنو» و اعتبار طراح «مهدی نامدار» حفظ شده‌اند.
- نام نصب‌شده اپ: **Smart Bundle**.
- برای نصب PWA باید سایت از HTTPS یا localhost اجرا شود؛ باز کردن مستقیم با `file://` کافی نیست.
- خروجی Excel در رابط فعلی به صورت CSV سازگار با Excel است و خروجی PDF از پنجره چاپ مرورگر استفاده می‌کند.


## منطق مالی اصلاح‌شده

بودجه نهایی باندلینگ هر سفارش با فرمول زیر محاسبه می‌شود:

`تعداد Cashless × (قیمت فروش هر Cashless − بهای تمام‌شده هر Cashless − سود ثابت هر Cashless) − تعداد کارتخوان × بودجه بازاریابی هر کارتخوان`

بودجه بازاریابی فقط در همین فرمول برای محاسبه بودجه قابل‌تخصیص به باندلینگ لحاظ می‌شود و هیچ بخش جداگانه‌ای برای نحوه مصرف آن تعریف نمی‌شود. تعداد کارتخوان‌ها می‌تواند هر عدد صحیح مثبت باشد و مضرب ۵ بودن اجباری نیست.

مقادیر نمونه: قیمت مستقل کارتخوان ۲۰، قیمت هدف ۱۵، بهای تمام‌شده Cashless برابر ۲۵، قیمت فروش Cashless برابر ۴۰، سود ثابت هر Cashless برابر ۲ و بودجه بازاریابی هر کارتخوان برابر ۲ میلیون تومان. برای بسته شتابی ۱۰ کارتخوان و ۵ Cashless، بودجه باندلینگ ۴۵ میلیون تومان و قیمت هر کارتخوان ۱۵٫۵ میلیون تومان می‌شود.
